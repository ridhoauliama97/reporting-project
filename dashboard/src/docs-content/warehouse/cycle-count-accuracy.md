# Cycle Count Accuracy (Akurasi Stock Opname)

## Deskripsi
Laporan akurasi hasil cycle count (stock opname berkala) — membandingkan hasil hitung fisik terhadap saldo sistem.

## Kegunaan
Mengukur keandalan catatan persediaan; akurasi tinggi berarti saldo sistem dapat dipercaya untuk pengambilan keputusan.

## Data yang Seharusnya Diperlukan
- Hasil hitung fisik per lokasi per periode
- Saldo sistem pada saat penghitungan
- Catatan selisih (variance) dan tindak lanjutnya
